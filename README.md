# JeniK Beauty Choice — Demo Website

A responsive one-page beauty salon website concept built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page structure and content
- `styles.css` — pink + cream styling and responsive layouts
- `script.js` — mobile navigation, enquiry form and placeholder social-link handling

## Run locally
Open `index.html` in a browser. For a local development server, use VS Code Live Server or run:
`python3 -m http.server 8000`
Then open `http://localhost:8000`.

## Before publishing — important checks
1. Confirm the business owner has approved the website and the use of the business name.
2. Confirm the phone number and WhatsApp number. The current number in `script.js` is derived from the screenshot and is NOT verified.
3. Confirm the full address and current opening hours.
4. Confirm every listed service, price, treatment claim and booking process with the business.
5. Replace all sample Unsplash images with photos the business owns or has permission to use.
6. Replace the `#` Facebook, Instagram and TikTok links in `index.html` with official profile URLs.
7. Add a real logo and any privacy/legal information the business needs.
8. Check all links and the site on a real phone before launch.

## Deployment
You can deploy this folder using Netlify Drop or push it to a GitHub repository and enable GitHub Pages. Use the folder contents, not the ZIP file's outer folder, if a host asks for a publish directory.

This is a demo concept, not an official website. Do not imply that services, prices, ratings, photos or contact information are verified until the business confirms them.
