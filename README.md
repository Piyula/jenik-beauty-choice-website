# 💄 JeniK Beauty Choice

✨ A responsive, single-page beauty salon website for **JeniK Beauty Choice** in Jaffna, Sri Lanka. The website introduces the business, highlights beauty services, showcases an image gallery, and allows visitors to prepare appointment enquiries through WhatsApp.

🌐 **Live Website:** [JeniK Beauty Choice](https://jenik-beauty-choice.netlify.app/)

---

## ✨ Features

- 📱 Responsive layouts for desktop, tablet, and mobile screens
- 🍔 Mobile navigation with accessible expanded-state labels
- 🏠 Home, About, Services, Gallery, and Contact sections
- 💅 Service enquiry links that preselect a service in the contact form
- 💬 WhatsApp enquiry form with name, service, preferred date, and message fields
- 📞 Contact details and social media links
- 🎨 Custom website logo and favicon
- ♿ Semantic HTML landmarks and accessibility considerations
- 🌿 Reduced-motion support for a more comfortable browsing experience

---

## 🛠️ Built With

- 🧱 **HTML5** – Website structure and content
- 🎨 **CSS3** – Styling and responsive layouts
- ⚡ **Vanilla JavaScript** – Interactive features and form behavior
- 🔤 **Google Fonts** – DM Sans and Playfair Display
- 🖼️ **Unsplash** – Sample photography

✅ No package installation or build step is required.

## 🚀 Run Locally

Follow these steps to run the website on your computer.

**1️⃣ Open the project directory** in your terminal.

**2️⃣ Start a local static server:**

```bash
python3 -m http.server 8000
```

**3️⃣ Open the website** in your browser:

🔗 [http://localhost:8000](http://localhost:8000)

## ⚙️ Configuration and Content Checks

Before presenting this website as the official website of JeniK Beauty Choice, verify the following details with the business owner.

- 🏷️ **Business Information:** Confirm the business name, address, phone number, and WhatsApp number.
- 💅 **Beauty Services:** Verify the services offered, prices, opening hours, and appointment process.
- 📱 **Social Media:** Check all social media profile links.
- 🖼️ **Photography:** Obtain permission to use every photograph. Replace sample Unsplash images with approved salon photographs where possible.
- 🔒 **Privacy and Accessibility:** Determine whether privacy notices, accessibility statements, or other legal notices are required.

### 📲 WhatsApp Configuration

The WhatsApp number is configured in `script.js` using the `WHATSAPP_NUMBER` variable.

Use the international phone number format with digits only, including the country code.

📌 The contact address, telephone link, social URLs, image URLs, and website copy are maintained in `index.html`.

💬 **Important:** The enquiry form opens WhatsApp with a prefilled message. It does not automatically send messages or store form submissions on a server.

## 🌍 Deployment

🚀 The website is deployed using Netlify.

🔗 **Live Website:** [https://jenik-beauty-choice.netlify.app/](https://jenik-beauty-choice.netlify.app/)

To deploy an updated version:

1. 📁 Open your project directory.
2. 🌐 Upload or publish the project directory through Netlify.
3. ⚙️ Set the project root containing `index.html` as the publish directory.
4. ✅ Deploy the website.

No build command is required because this is a static website.
